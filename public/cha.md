# 第一章 三次死亡

# 一看到無差別殺人案，理論上的創作方法就是把看成是一個統一的事件，開頭出現人物都會被趕到這個圓圈當中去。從《ABC殺人案》開始，這種類型的作品特別受到注目。一般情況下，我們都會把這個題材跟「消失的圓環」或者「童謠殺人」聯繫在一起。不過這種變態殺人——表面上看——的題材，應該可以有更多的表現形式。

# 「是這個案子，委託人是死者的大學同學和好友，幾個人一起出錢做的委託。是稀奇古怪的案件沒錯，而且我也有意受理這個案子……」

# 「是那個在好幾個偵探的監視之中，殺人兇手卻從中消失的案子，對吧？」

# 「我聽說兩個人私下裡貌似有那種關係。」

# 雖然對案件完整情況不甚了解，但這個部分龍藏還是有把握的。而且龍藏也略微知道點報紙上登載的那種「大都會裡的性與愛」的報道，也算是間接的情報了。

# 「這沒什麼不可思議的。僱主和打工的僱員間這樣的事情是常有的事。」

# 「你說的對。這樣的事情確實沒什麼不可思議的。至少女孩子的父親一直對此耿耿於懷，找了兩個偵探對他進行調查。」

# 「啊，然後這兩個偵探目擊到了男子進了房間。原來如此。」

# 這麼關鍵的節點，龍藏還是第一次聽到。誠然事件對他來說有一點印象，但並沒有怎麼關注這件事情。一個案子每個人都眾說紛紜，一些關鍵點反而能夠避開關注。

# 「確實如此。」

# 「這不是很有意思的案件么？」

# 「不，這個有趣得過分了。」

# 偵探又稍微有點斜眼。注視著纏在一起的手指。

# 「也就是說……即使我不接這個案子，在半個月前也已經在著手這個案子了。」

# ——啊，是這樣啊。

# 龍藏算是完全明白了。仔細想想，像新寺這樣喜好解謎的人，不應該就這樣放著案子不管的。

# 「那麼最終有把消失之謎解開么？」

# 「不用說當然解開了……好吧，告訴你也無妨。男子是通過那個房間的垃圾通道出去的。」

# 「垃圾通道？……就是那種大樓裏面設置的用來扔垃圾的洞穴？」

# 因為龍藏根本不知道案發現場還有這種情況存在，因此連這樣常見的解答都沒想到，反倒第一反應是「這解答挺出人意料啊。」

# 新寺之前把大學學的都市論和偵探學結合起來學了一本書還出版了，這好像書裏面說的話。

# 「原來如此，那麼自然就是在這兩天里去找找有沒有合適的，用土填好的洞穴基坑就好了。就像電視劇《神探科倫坡》裏面演的那樣……」

# 「那麼後面就只要找到屍體的事情了。可以把這個喜訊報告給委託你的那些女孩子們了。」

# 無論怎樣解釋，龍藏還是對新寺的處理不滿。儘管站在兇手的立場，她有值得同情的地方。但是新寺這樣一邊對世人熟知的難解案件做出合理解釋，一邊又把功勞掩蓋起來，實在荒謬。

# 「新寺君，你從過去開始就就不愛爭取功名。多說一句，也不愛爭利。以前作為素人偵探這樣暫且不論，可是現在你已經是正經的職業偵探了，還是這樣的職業意識是絕對不行的。要儘快打響自己的名聲，也不要過分挑剔案子的委託。一本《都市與偵探》始終是不能吸引多少客戶的，過去的業績和書的版稅是一樣的道理，如果沒有新的那一切又都回到原點了。」

# 「哎呀，有你在我都不用找老婆了啊。」

# 新寺格格地笑著，完全沒把龍藏的意見當回事。開始說他還有一個「一看就想要親自出馬的委託」這樣的話。

# 只是話音未落，電話鈴聲就響了起來。他一邊拿起話筒，一邊和龍藏耳語了一句。

# 「我們不必去挑案子，因為這座城市案子會自己找上門來。」

# 他對這座城市和這座城市的犯罪事件的了解的強大自信都濃縮在了這句話中。

# 而事實上，在未來，有件比這個公寓殺人還有怪誕的生人消失事件在等待著新寺和龍藏。

# 假如把社會發生案件的種類比成流行風向標的話，這次公寓殺人案絕對可以榜上有名，而隨後詭異的高塔連續消失案則是站在尖端的頂級風向標的存在。

# 當被問到難以回答的問題的時候，總會以「我不知道」作答，這是新寺仁和雷津龍藏的共有的習慣。只不過兩人稍微有些差異，前者會把問題細細思索過後才會做出回答，而後者則脫口而出的。

# 他的深思熟慮可以從兩年前畢業的大學生活中的兩點體現出來。

# 一個是他追求縝密到極致的論文。他專業研究方向雖然是現代都市現象的構成和分析，但傾注他最多研究精力的卻是「智能犯罪學」這個分項。特別是他的調查又集中在全國聞名遐邇的犯罪都市高塔市，在海量資料的輔助之下，他完成了三篇有關智能犯罪構成的論文。

# 這時候留衣的目光一直對著新寺。

# 「半個月前來這個店的那個女孩。」

# 「哇，這真的很意外啊。留衣你經常去那家店買東西么？」

# 「買東西倒不是很經常，不過那裡是從車站到學校的必經之路。——不知不覺間就和小純交上了朋友。第一次相遇應該是和哥哥一起來這座大樓的時候。」

# 雖然偵探事務所和成衣店並沒有什麼業務往來，不過把進入自己生活圈子中的對象，變成自己的朋友，一直是她的癖好。

# 「今天早上也是九點從這裏經過的，可是非常意外，小純和店長都沒有在外面。到底怎麼了？真是很擔心啊。」

# 看起來和那個女孩很親密的樣子，留衣提著包，非常挂念地向一片漆黑的商店內部觀望。全玻璃幕牆的內牆雖然只掛著窗帘，店內的燈都關掉了，所以內部的情況一點也看不清楚。這家店在同類型的商店當中屬於中等規模，不過在「closed」的牌子上面貼著一張寫著「招募店員（僅限年輕女孩）」的貼紙，看來也是人手不夠。

# 「一定是感冒請假了。」

# 龍藏的回答顯得很合理。留衣只是簡短地回答了一句「應該是吧。」就店門前離開。她用和她小個身體不相稱的快速腳步，三步並作兩步地向前走著。

# 「喂，新寺。」

# 等到留衣在前方已經走遠了，龍藏才把心裏還挂念著問題直接向新寺問道。

# 「剛才說的那個店的店長……」

# 「是女的。」

# 新寺用一副這還用說么的語氣回答道，喉嚨微微地哼哼到。

# 「很介意？」

# 「沒，沒有，怎麼會……只是覺得留衣醬這麼可愛，要是被什麼奇怪的男人盯上……」

# 「沒事的，那傢伙跟我一樣都有觀察異性的眼光，不管和誰交往，都不會是那種令人可疑的男人。放心吧。」

# 「……好吧。」

# 龍藏只好先點頭同意，其實留衣交往的異性到底是好是壞，這個時候他也顧不了那麼多了。

# 「那個……留衣有交往對象么？」

# 「她也是十六歲的少女了啊，有一兩人交往的異性，不是問題吧。」

# 這回答實在過於理所應當了。毫無疑問不能讓龍藏心裏的石頭落下地來。

# 「你們在幹什麼，快點，到店裡去看看。」

# 留衣注意到了兩人掉了隊，轉過頭來招呼道。臉上依然是無憂無慮的表情，對龍藏的消沉那是一無所知。

# 更不要說，她如何也不會想到殘忍的死神會對一分鐘前還十分挂念的好朋友下手。

# 「馬上就來。」

# 像是在對妹妹大嗓門表達不滿，新寺也用很大的嗓音回應道，然後為了趕上留衣加快了步伐。一直低著頭不知道在想些什麼的龍藏，隨後也跟了上去。

# 不過他突然想起了什麼重要的事情。對身前的新寺小聲耳語道：「請等一下，新寺君。」

# 「什麼？」

# 「有兩個交往對象難道不是問題么？」
