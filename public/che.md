# 後記

# 您好，初次見面。最近啊，我在構思了這樣的魔術，名字就叫它「消失」。

# 形式就是「本格推理」。表演的主題就是「人的消失」以及「無差別連環殺人」——當然，這些始終都只是表面現象，並不是人真的消失，也沒有無差別殺戮（這是顯然的）只是乍看上去是這樣，所以夠得上是魔術中的魔術。

# 「人的消失」是一種非常常見的現象。在推理小說中出現的多種謎題當中，毫無疑問是特別具有衝擊力的謎題。曾經一個晚上，迪克森卡爾和艾拉里奎因曾經就推理小說的存在形式徹夜長談，得出結論，「人的消失」是推理小說最重要的起源，這是非常有名的故事。

# 還有「無差別殺人」。

# 這也是耳熟能詳的一個主題了。相互沒有任何關聯的人們相繼被一個殺人狂魔所害……大致這樣的橋段組成了小說的情節模式。約翰？羅德的《普里德街謀殺案》，阿加莎克里斯蒂的（傑作！）《ABC謀殺案》，艾拉里奎因的《九尾怪貓》，最近還有William Louis DeAndrea的The HOG Murders數本名篇給這樣模式提供了各種解答。

# 無論怎麼說，這都是「推理小說的王道設計」

# 但是同時我們也可以說這是一種模式已經被挖掘殆盡，許久不見的推理類型。和讀者朋友們初次見面，就馬上要應付這麼困難的題材，我可能也是太魯莽了。

# 只是，如果各位說我魯莽，估計是因為本作使用的詭計，在心理層面上過於龐大了。瑣碎的釣魚線和大頭針密室詭計，對兩次還不能理解的複雜時刻表詭計，對我自己來說是非常反感的。除去稍顯漫畫式的輔助詭計（雖然如此，但應該還是有點意外吧）主詭計恐怕沒有前人寫過吧。（嗯，這是非常強硬的發言）

# 無論如何，在我最近構思的魔術當中，這是非常有自信的作品。從這裏開始閱讀本編的你，請對文中發生的現象給予足夠的困惑，請試著推理詭計手法，如果你有這麼做的話……對結尾揭秘的部分，一定會震驚的。

# 最後，作為一個新人作家，按照慣例，對長久以來幫助我的各位寫上一些感謝的話語。

# 首先是，僅僅因為一本短篇就推薦我的綾辻行人先生和我孫子武丸先生。我從心底感謝你們兩位大胆的舉動。給你們添了不少麻煩。

# 然後是書中同道堂裕子的原型，M桑（她那種猶如超能力者一般的直覺就是受到你的影響）才華橫溢的京大推研會的各位同仁。能寫這部作品都是你們的功勞。

# 還有最重要的，講談社的宇山日出臣先生。對這樣一個不聽話的新人，一直緘口不言。實在太照顧了。

# 那麼，對正在閱讀這本的各位致以最高的感謝，希望早一天跟各位再見。
